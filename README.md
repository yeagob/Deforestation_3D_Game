## 📖 Concepto del Juego

Deforestation es un innovador juego de supervivencia que combina mecánicas de FPS en primera persona con control de robot en tercera persona y un profundo sistema de gestión de recursos.

### 🌟 Historia

Eres un trabajador especializado de una empresa de recolección de recursos en un mundo post-apocalíptico. Tu misión principal es reparar tu robot recolector averiado mientras navegas por territorios peligrosos, recolectas recursos vitales y luchas por regresar a la base sano y salvo.

### 🎯 Objetivos del Jugador

- **Supervivencia**: Mantente con vida en un entorno hostil
- **Reparación**: Diagnostica y repara tu robot recolector dañado
- **Recolección**: Gather recursos esenciales para las reparaciones y supervivencia
- **Exploración**: Navega por el mundo para encontrar componentes y rutas seguras de regreso
- **Optimización**: Gestiona eficientemente tus recursos limitados

## 🎮 Características Principales

### 🚶 Modo Jugador (FPS)
- **Movimiento fluido**: Sistema WASD completo con físicas realistas
- **Salto dinámico**: Mecánicas de parkour básico
- **Interacción avanzada**: Sistema de inspección detallada de objetos
- **Inventario inteligente**: Gestión de recursos y herramientas

### 🤖 Modo Robot (Tercera Persona)
- **Control preciso**: Manejo intuitivo del robot recolector
- **Sistema de combate**: Capacidades de disparo y defensa
- **Movilidad enhanced**: Salto y navegación especializada
- **Capacidades únicas**: Habilidades que el jugador no posee

### 🔧 Sistema de Reparación
- **Diagnóstico**: Identifica componentes dañados
- **Upgrade system**: Mejora las capacidades del robot
- **Crafting**: Creación de piezas de repuesto
- **Modularidad**: Sistema de componentes intercambiables

### 🔄 Mecánicas Híbridas
- **Cambio de perspectiva**: Transición fluida entre modos
- **Sinergia**: Tareas que requieren ambos modos
- **Estrategia dual**: Diferentes enfoques para resolver problemas

## 🛠️ Especificaciones Técnicas

### 🎨 Arte y Estética
- **Estilo visual**: Low-poly realista inspirado en la estética robótica
- **Paleta de colores**: Tonos industriales con acentos tecnológicos

- **Actual**: PC (Windows, Mac, Linux)

### 🎯 Target Audience
- **Primario**: Desarrolladores y empresas de videojuegos

### ⚡ Requisitos del Sistema

- **OS**: Windows 10 64-bit

## ⚙️ Instalación

### 📥 Descarga
```bash
git clone https://github.com/yeagob/Deforestation_3D_Game.git
cd Deforestation_3D_Game
```

### 🔧 Configuración
1. Instalar dependencias del motor de juego
2. Configurar variables de entorno
3. Compilar assets
4. Ejecutar build inicial

### ▶️ Ejecución
```bash
./Deforestation3D.exe
```

## 🎯 Controles

### 👤 Modo Jugador (FPS)
- **Movimiento**: W, A, S, D
- **Salto**: Espacio
- **Interactuar**: E
- **Inventario**: Tab
- **Cambiar modo**: ESC

### 🤖 Modo Robot
- **Movimiento**: W, A, S, D
- **Salto robot**: Espacio
- **Disparar**: Click izquierdo
- **Modo de reparación**: R
- **Cambiar modo**: ESC

### 🔧 Modo Reparación
- **Inspeccionar**: Click derecho
- **Seleccionar herramienta**: 1, 2, 3, 4
- **Aplicar reparación**: F
- **Rotar componente**: Mouse wheel
